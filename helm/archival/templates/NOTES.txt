Archival CronJob and Deployment
==============================

This chart deploys:
- A CronJob that runs the archival handler on schedule (default: midnight daily)
- A Deployment (for debugging/ops)

To check CronJob runs:
  kubectl get cronjobs
  kubectl get jobs

To check logs of a job:
  kubectl logs job/<job-name>

To run the archival handler manually in a pod:
  kubectl exec -it deploy/<release-name>-archival -- python /code/apps/archival/handler.py
